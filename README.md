# DraftPilot for Skool

Chrome Manifest V3 extension that drafts replies to Skool posts and comments using the user's own Anthropic API key. It never submits a post automatically.

## Load locally

1. Open `chrome://extensions`.
2. Enable Developer mode.
3. Choose **Load unpacked** and select this folder.
4. Open **Extension options** and add an Anthropic API key.
5. Open a Skool post or comment thread and use **✨ Draft reply**.

Free plan: 10 successful drafts per local calendar day. Pro licensing is verified through Gumroad after the Pro product ID is assigned.
